# dev2 相对 main 的功能与发布差异

本文记录 `dev2` 在 `v2.0.12` 时相对 `main` 的独有改动，供测试、发布和后续合并时核对。它不重复列出已经合并到 `main` 的远程桌面、SSH Agent、主题和引导流程等功能。

## 面向用户的功能

### 定时终端输入

终端命令栏新增“定时输入”按钮。弹框内可以直接输入或编辑要发送的命令，也会在打开时带入命令栏中已有的内容：

- 支持延时执行、指定时间执行一次和每天定时执行；延时范围为 1 分钟至 30 天，指定时间可按 1 分钟调整，每日时间按 15 分钟调整。
- 到时会向目标终端发送命令栏文本并追加 Enter；终端即使处于后台也会尝试执行。
- 每个终端独立显示、删除和计数自己的任务。一次性任务成功发送后自动移除；每日任务成功后自动计算下一次执行时间。
- 终端暂时不能接收输入时，任务会保留为待发送状态，并在终端恢复可输入后重试。SSH 终端因重连而重建时，已有任务会绑定到新的终端会话。

当前限制：任务只保存在正在运行的应用内存中，退出应用后不会恢复；串口终端不提供该功能。

### 终端内联命令补全

在 shell 提示符后直接输入命令时，终端会根据当前终端已执行的非敏感命令显示灰色内联建议：

- 使用上、下方向键在最多 8 个前缀匹配建议之间循环选择，使用右方向键接受当前建议。
- 备用屏幕、终端鼠标协议和非 shell 输入状态不会显示建议，也不会占用应用程序的方向键。
- 疑似包含密码、令牌、私钥或认证参数的命令不会进入建议历史；候选文本使用可清零的临时内存持有。

### 自动折叠侧边栏

外观设置新增“自动折叠侧边栏”，默认开启。开启后，创建本地终端、打开 SSH 终端或打开连接时，会自动收起左侧边栏以增加终端可用宽度。该设置可随时关闭，并会作为外观设置参与现有设置快照与同步流程。

### 复制 SSH 会话

SSH 终端标签的右键菜单新增“复制会话”。该操作会基于同一个 SSH 节点配置创建另一个终端标签，适合在同一主机上并行查看日志和执行命令。它只对 SSH 终端可用；复制后的标签是独立终端使用者，关闭任一标签不会错误地终止另一个标签所需的连接资源。

## 发布与交付调整

`dev2` 的原生发布工作流针对当前可用平台进行了收敛：

- 仅构建 macOS Apple Silicon、Windows x64 和 Windows ARM64，不再构建 macOS x64 与 Linux 两种架构。
- 发布仅由符合约定的版本标签触发；该分支不发布应用内更新清单，也不要求更新器签名密钥。
- Windows NSIS 安装器使用应用图标作为安装与卸载界面图标，并保留手动安装的交互过程，不再把已有旧安装静默视为自动更新。

## 验收建议

- 在本地和 SSH 终端分别创建一次性、每日定时任务；在执行前切换到其他标签，并验证任务仍会执行。
- 创建指定时间的一次性任务，并验证任意分钟值和弹框内直接输入命令均可用。
- 重复执行若干同前缀命令，验证上下键切换建议、右方向键接受建议，并确认 Vim 等全屏程序仍接收自己的方向键。
- 在 SSH 重连后确认未执行的任务仍关联到重建后的终端；退出并重新打开应用后，确认定时任务不会被错误地保留。
- 开启和关闭自动折叠侧边栏后分别打开本地终端和 SSH 连接，确认行为与设置一致。
- 在 SSH 标签右键复制会话，确认新标签可独立输入、关闭其中一个标签后另一个仍可使用。
- 在 Windows 测试交互式安装器，确认安装器、已安装应用和卸载入口显示正确图标。
